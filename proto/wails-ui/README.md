# Прототип интерфейса на Wails v3

Шаг 0 плана: прежде чем переводить клиент на Wails, проверить на трёх ОС окно у иконки трея
и тосты справа вверху. Отдельный модуль: `go test ./...` в корне его не собирает, клиент от него
не зависит. Данные выдуманные, брокера нет.

## Запуск

```sh
cd proto/wails-ui
go run .                       # трей: левый клик — окно, правый — меню с тостами
go run . -demo                 # сразу окно, уведомление и вопрос о задании
go run . -demo -exit 15s       # то же, через 15 с — отчёт REPORT и код 1, если что-то не так
CGO_ENABLED=0 go run -tags purego .   # macOS и Linux без cgo
```

Переменные для сравнения: `PROTO_WIN_SHOW=wails` — на Windows показывать тост только через Show()
Wails, без SW_SHOWNOACTIVATE; `PROTO_WAYLAND=1` — на Linux не переходить на XWayland.

## Что проверяем

| Вопрос | Как |
|---|---|
| Собирается без cgo под все ОС с одного раннера, как нынешний релиз | задача `build` в `.github/workflows/proto-wails.yml`: `-tags purego` для macOS и Linux |
| Размер бинарника | таблица в сводке задачи `build` |
| Тост встаёт в правый верхний угол рабочей области, столбик пересобирается | отчёт: `want` против `x`, `y` |
| Тост не забирает фокус | отчёт: `focused`; на Windows — поверх Блокнота, в двух вариантах показа |
| Строки брокера остаются текстом при строгом CSP | отчёт: `injectedElements` = 0; grep на `innerHTML` в CI |
| Мост JS ↔ Go работает при CSP без `unsafe-inline` | отчёт: `calls` |
| Внешний вид | `shot.png` в артефактах каждой задачи |

Руками, на живом столе (CI этого не покажет):
- macOS: печатаешь в редакторе, приходит вопрос о задании — набор не прерывается, кнопки
  нажимаются с первого клика;
- Windows: то же; тост над панелью задач, когда она сверху или сбоку;
- Linux GNOME (Wayland): иконка в трее с расширением AppIndicator, тост в углу через XWayland;
- окно у трея: открывается у иконки, прячется по Esc и при уходе фокуса, поле ссылки и ⌘V работают.

## Что уже выяснилось

- Без тега `production` Wails берёт страницы с адреса из `FRONTEND_DEVSERVER_URL`. Релиз клиента
  собирать только с `-tags production`.
- На Wayland Wails не умеет ставить окно в заданное место и держать поверх остальных (это делается
  через X11). Прототип запускает GTK через XWayland (`GDK_BACKEND=x11`), если тот есть.
- `IsVisible()` на macOS смотрит, видно ли окно на экране (occlusion): на заблокированном экране
  все окна «невидимы».
- В скрытом окне не срабатывает `requestAnimationFrame`: тост меряет высоту сразу.
